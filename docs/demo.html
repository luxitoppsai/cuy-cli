Alcance visible

Entender y revisar son de lectura. Corregir conserva sus cambios en un worktree separado.

Evidencia antes que promesas

Las referencias se comprueban. Una corrección solo figura verificada cuando las pruebas elegidas pasan.

El siguiente paso es tuyo

Inspeccioná el diff y el informe. El flujo no aplica, publica ni reanuda cambios automáticamente.
